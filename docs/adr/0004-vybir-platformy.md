# ADR-0004. Вибір платформи цифрового двійника

## Контекст

Для лабораторного стенда потрібно приймати телеметрію роботизованого художнього манекена, зберігати поточний стан і надавати доступ до нього через HTTP API. Платформа має підтримувати локальне розгортання на навчальному ПК, відтворювані вимірювання та інтеграцію з MQTT, обраним у ЛР1. Ваги критеріїв, джерела й розрахунок наведено у [порівнянні платформ](../platform.md#порівняння-платформ).

## Варіанти

| Варіант | Переваги для проєкту | Обмеження | Зведена оцінка |
|---|---|---|---:|
| Eclipse Ditto | Локальне розгортання, відкритий код, MQTT, HTTP API та WoT Thing Model | Власний супровід, окреме сховище історії | 4,55 |
| Azure Digital Twins | Керований граф двійників, відкрита специфікація DTDL, документовані квоти | Хмарний екземпляр, окрема інтеграція телеметрії, оплата за використання | 2,85 |
| AWS IoT TwinMaker | Керована платформа, граф знань, з’єднувачі та 3D-сцени | Хмарний робочий простір, залежність від джерел даних і проміжна інтеграція MQTT | 2,30 |

## Рішення

Для стенда ЛР2 обрано Eclipse Ditto 3.9.7 з локальним розгортанням через Docker Compose. Mosquitto прийматиме MQTT-телеметрію, а Ditto зберігатиме поточний стан двійника та надаватиме його через HTTP API. Історик отримуватиме зміни стану від Ditto і записуватиме їх в InfluxDB для перегляду в Grafana.

Цим рішенням уточнено [ADR-0001](0001-data-storage.md) для стенда ЛР2. InfluxDB використовується для історії телеметрії з терміном зберігання 7 діб. Питання постійного зберігання іменованих поз і журналу команд залишається в межах архітектури ЛР1.

## Наслідки

- Стенд можна розгортати й відтворювати на навчальному ПК. Команда відповідає за ресурси Docker, налаштування й супровід служб.
- Поточний стан і історія зберігаються окремо. Для історії потрібен історик, який читає події SSE від Ditto та записує їх у InfluxDB.
- Перевірка HTTP API вже підтвердила створення та читання тестового двійника. Підключення телеметрії, вимірювання затримки та межі пропускної здатності перевірятимуться на наступних етапах.
